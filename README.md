# 🚀 My PIM (Personal Information Manager) - 완전체 매니저

나만의 일정, 할 일, 메모를 한곳에서 완벽하게 관리할 수 있는 가볍고 직관적인 PIM 웹 애플리케이션입니다. 
Node.js와 SQLite를 기반으로 작동하며, Docker를 통해 언제 어디서든 쉽게 배포하고 실행할 수 있습니다.

## ✨ 주요 기능 (Features)

### 📅 1. 일정 관리 (Calendar)
* **직관적인 달력 UI**: 월별 달력과 오늘 날짜 하이라이트, 주말(토/일) 색상 구분
* **한국 공휴일 지원**: 2026년 ~ 2030년까지의 명절, 국경일, 대체공휴일 등 자동 표시
* **드래그 앤 드롭**: 등록된 일정을 드래그하여 손쉽게 날짜 변경 가능
* **카테고리 및 툴팁**: 카테고리별 색상 라벨링 기능과 마우스 오버 시 상세 메모를 보여주는 커스텀 툴팁 제공

### ✅ 2. 할 일 관리 (Todo)
* **폴더 및 하위 할 일**: 폴더별로 할 일을 분류하고, 드래그 앤 드롭으로 1단계 하위 할 일(Sub-task) 생성 가능
* **자유로운 순서 변경**: 드래그 앤 드롭으로 할 일 항목과 폴더의 순서를 원하는 대로 배치
* **스마트 필터링**: '미래 숨기기', '완료 숨기기' 체크박스를 통한 효율적인 목록 관리
* **반복 설정**: 매일, 매주, 매월 등 반복되는 할 일 등록 및 🔄 아이콘 시각화

### 📝 3. 메모장 (Notes)
* **트리 구조 폴더 관리**: 메모를 폴더별로 깔끔하게 정리하고 접기/펴기 지원
* **드래그 앤 드롭 관리**: 메모를 다른 폴더로 이동하거나 폴더 간의 순서 변경 가능
* **자동 저장 (Auto-save)**: 타이핑 후 1초 대기 시 서버에 자동으로 저장되어 데이터 유실 방지
* **쾌적한 편집기**: 화면을 넓게 사용하는 가독성 높은 텍스트 에디터

### 🛡️ 4. 인증 및 시스템 관리 (Auth & Admin)
* **회원가입 및 승인제**: 가입 후 관리자의 승인(Approve)이 있어야만 로그인 가능한 폐쇄형 시스템
* **관리자 대시보드**: 가입자 목록 조회, 승인, 계정 삭제 기능 제공

---

## 🛠️ 기술 스택 (Tech Stack)

* **Frontend**: HTML5, CSS3, Vanilla JavaScript (No Frameworks)
* **Backend**: Node.js, Express.js
* **Database**: SQLite3 (로컬 파일 DB)
* **Deployment**: Docker, Docker Compose

---

## 🚀 실행 방법 (How to Run)

### 1. Docker를 이용한 실행 (권장)
가장 빠르고 안전하게 앱을 실행하는 방법입니다. 데이터베이스는 로컬 `data` 폴더에 안전하게 보관됩니다.

```bash
# 저장소 클론
git clone <저장소 주소>
cd my-pim-app

# Docker Compose로 백그라운드 실행
docker-compose up -d --build
